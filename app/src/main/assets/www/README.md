# HTML PPT 使用说明

纯文本编写 PPT，**一次编写，可放映、可导出单文件 HTML**。

数据目录：`/sdcard/HTML_PPT/`

---

## 目录说明

```
/sdcard/HTML_PPT/
├── www/        界面文件（一般不要动；想改可编辑后重启 App）
├── PPT/        你的演示文稿（.txt，每页用 --- 分隔）
├── themes/     自定义主题（.json / .css）
├── Download/   导出的单文件 HTML
├── settings.json   全局设置（主题/进度条等）
└── README.md   本说明
```

---

## 编写演示文稿

在 `/sdcard/HTML_PPT/PPT/` 新建 `.txt` 文件，用**纯文本**写，每页之间用一行 `---` 分隔。

### 分页与结构
```
---              # 页面分隔线
# 标题
## 副标题
### 小节标题
```

### 富文本
```
- 列表项
1. 编号项
> 引用
**加粗**  *斜体*  `代码`
[链接文字](https://...)
![说明](图片URL)      # 图片
```

### @ 指令
```
@center          整页居中（适合封底/金句）
@t(页脚文字)      设置页脚
@theme(主题名)    指定该页主题
@progress:show|top|颜色|段落|比例   分段进度条
|段落名|          从这页起进入「段落名」（进度条分段）
```

---

### 示例

```
@progress:show|top|aurora|1|20,20,20,20,20

|开场|
# 我的演示
## HTML PPT

|正文|
- 支持列表、图片、链接
- 用 @center 居中
![示例图](https://picsum.photos/900/500)

|结尾|
@center
# 谢谢观看
@t(HTML PPT)
```

## 自定义主题

用 `@theme-def` 定义该 PPT 专属主题，可写进度条颜色 `pb`：

```
@theme-def:晨曦 c1:#fdf6ec c2:#f8e2c8 c3:#f3cfa4 accent:#e0703c text:#3a2b1b muted:#9a826a pb:#2b8a8a
@theme-def-end
@progress:show|top|晨曦|1
```

字段：`c1/c2/c3`（背景渐变）、`accent`（强调色）、`text`（正文色）、`muted`（次要色）、`pb`（进度条颜色）。

## 放映

- 主页点卡片「**播放**」进入全屏放映。
- 左右滑动 / 按左右键翻页。
- 顶部/底部**分段进度条**：当前段落高亮，点击可跳转；段落之间为浅色竖线分隔。

---

## 导出单文件 HTML

- 打开演示 → 点「**导出**」→ 保存到 `Download/`。
- 导出的 HTML **单文件、可独立打开放映**：长按呼出「**全屏 / 自定义主题**」。
- **本地图片会转成 base64 内嵌**，拿到任何设备都能显示；网络图需联网。

---

## 主题与设置

- 主页右上角「主题圆点」切换全局主题（内置 6 套）。
- 「设置」页可配置默认主题、进度条位置等。

---

## 遇到的问题

| 现象 | 处理 |
|------|------|
| App 里网络图片不显示 | 已授权网络权限；联网后刷新 |
| 本地图片导出后仍不显示 | 用**绝对路径**：`file:///storage/emulated/0/HTML_PPT/xx.png` |
| 想换界面外观 | 编辑 `www/theme.css` 后重启 App |
| 想改编辑器逻辑 | 编辑 `/sdcard/Download/HTML_PPT/index.html` 后重启 App |
